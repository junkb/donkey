= donkey

an xmpp client for macos, built in honor of https://adium.im/[adium].

== status

pre alpha. nothing works yet.

== what this is

adium was, and arguably still is, the best chat client macos ever had. it has been
unmaintained for years: it crashes on current macos, and and binaries are
x86_64, so it won't run when rosetta is removed.

donkey is an attempt to carry forward what made adium good — its architecture, its
message styles, the feel of using it — as something narrower and current:

* xmpp only
* arm64 native
* modern apple frameworks
